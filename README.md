# PortalIcons

Shared image assets used for product, company, and module branding across the Karament and Polycyphers applications. This repository is served directly from GitHub's `main` branch; application email templates and announcements commonly reference files through `raw.githubusercontent.com/melejel2/PortalIcons/main/<filename>`.

## Asset groups

- Product and module marks, including `PAM.png`, `TOMWEB.png`, `SAM.png`, `MEG.png`, `TED.png`, `HR.png`, `inrx.png`, and `machinery.png`.
- Company and partner logos, including `keh-logo-light.png`, `keh-logo-dark.png`, `SEG-INFRA.png`, and `WithSteel.png`.
- ACF brand variants, including `ACF-Bull*.png` and `ACFLogo.png`.
- Favicons, AI badges, and animated assets (`*.gif`).

There is no application source, build step, or generated asset pipeline in this repository. Preserve existing filenames when updating artwork because consumers address assets by filename. Before removing or renaming a file, search the application repositories for references to it.
